# Jump Stack

A mobile-first HTML5 canvas game where precision and timing are everything. Hold to charge your jump, release to launch — land on 100 platforms to win, but one miss and it's over.

## How to Play

- **Hold** to charge jump power
- **Release** to jump
- Land in the **center** of a platform for a **PERFECT**
- Get **3 perfects in a row** to earn an **extra life**
- Reach **0 jumps remaining** to win

## Features

- Smooth charge-and-release physics
- Dynamic difficulty curve across 100 jumps
- Two game modes: Classic and Extreme
- Achievement/trophy system
- Dark mode support
- Sound effects and haptic feedback
- PWA — installable on mobile and desktop
- Session persistence across page refreshes
